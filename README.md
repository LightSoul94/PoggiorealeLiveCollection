# Poggioreale LiveCollection

## Descrizione

Poggioreale LiveCollection è un progetto web sviluppato per la gestione e la visualizzazione di raccolte musicali in modo dinamico.
L’applicazione permette di organizzare contenuti e mostrarli in maniera semplice e immediata, con particolare attenzione all’esperienza utente.

---

## Tecnologie utilizzate

* HTML
* CSS
* JavaScript
* Bootstrap
* AJAX

---

## Funzionalità principali

* Visualizzazione dinamica delle raccolte musicali
* Aggiornamento dei contenuti lato client
* Interfaccia responsive e adattabile a diversi dispositivi
* Gestione e organizzazione dei dati in modo semplice

---

## Obiettivo del progetto

Questo progetto è stato realizzato per approfondire lo sviluppo frontend e la gestione dinamica dei dati lato client.
Ha rappresentato un’opportunità per migliorare le competenze in JavaScript e nella progettazione di interfacce web.

---

## Struttura del progetto

* `/index.html` → pagina principale
* `/css/` → gestione degli stili
* `/js/` → logica applicativa e gestione dinamica dei dati

---

## Possibili sviluppi futuri

* Integrazione con backend per la persistenza dei dati
* Gestione utenti e autenticazione
* Espansione delle funzionalità di ricerca e filtraggio
* Miglioramento dell’esperienza utente
